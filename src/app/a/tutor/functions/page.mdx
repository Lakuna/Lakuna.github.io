# TUTOR System Defined Functions

The following is an alphabetical list of system defined functions in the TUTOR language. It is not comprehensive. One of the sources, _The TUTOR Language_ by Bruce Anne Sherwood, has a Wiki version [here](https://codex.retro1.org/plato:tutor:start). Other sources include _Introduction to TUTOR_ by James R. Ghesquiere and the `introtutor` and `aids` lessons (accessed via [cyber1](https://cyber1.org/)). To see a complete description of any system defined functions, refer to the `aids` lesson.
