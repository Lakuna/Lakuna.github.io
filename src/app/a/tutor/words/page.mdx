# TUTOR System Defined Words

The following is an alphabetical list of system defined words in the TUTOR language. It is not comprehensive. One of the sources, _The TUTOR Language_ by Bruce Anne Sherwood, has a Wiki version [here](https://codex.retro1.org/plato:tutor:start). Other sources include _Introduction to TUTOR_ by James R.
